5/4 - 5/8

We're just about done with everything! The secret Pong game was about as much of a hit as Pong can be, so 4-Player pong is in discussion as a potential final feature.

So Mr. Crockett printed my IO port panel.

We installed that, but I had ideas on how to improve it. Michael was kind enough to print my new design with his multi-color-abled 3D-printer, so the final port cover looks much nicer than before.
We made a little low pass filter to mitigate the background noise created by the sound generation. It uses a ceramic capacitor my dad had in an old electronics box at home. The filter works to mitigate noise (especially when combined with some code changes I made over the weekend), but it's not strong enough for proper low-pass filter effects.

It's also safe to listen through headphones now (as long as you don't mess with the wiring inside).
Oh, and we made the brass instrument play an octave lower than the other instruments because it sounds better that way.

The base note is set to -12, the default lowest note, before the instrument is changed (just to make sure it's always set to that if it was somehow changed). Then, if it's switching to the brass instrument, the number is set to -24, which is an octave lower.
So, yeah, yay!
