4/6 - 4/10

We made a lot of tangible progress this week! Lots of settings and features added, and Weston brought in his amplifier for us to do some proper testing.
Some snippets!

We've added support for a sustain pedal, a "piano mode" with velocity-sensitive volume (instead of positional-sensitive volume), and the option to change the amount that key wiggle bends/modulates the note played.
Oh, yeah, Mr. Crockett also printed us some black keys for the keyboard! Now it looks a tiny bit more like a piano-type instrument.
Mr. Crockett has been asking me to add git commit links, so here's a pretty major one. This is where I combined my previous work to alter the code so it would work with the new Arduino Mega/16-key set-up with Weston's piano mode and sustain features. There were some bugs which I patched in the later commits before adding functionality for octave bending and toggling/cycling all these settings using the repurposed-joysticks' ability to be pressed in like buttons.


This image above shows the core code for the octave bend feature. It essentially sets the note frequency to that of a note one octave (12 notes) lower or higher than the note assigned to a key when said key is sufficiently bent left or right.
Here, I've started modeling final body/hardware/case for our instrument. The plan is to laser cut this out of wood.

Once we get this final body made and the guts of the instrument in it, I think we'll have something presentable for the capstone showcase. We'll continue to be able to add software features, but the hardware will be at a good stopping point.
Only 4 proper weeks of work left...
