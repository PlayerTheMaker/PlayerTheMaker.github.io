4/27 - 5/1 (- 5/3)

It's all together now! The project is basically done aside from some final touches, so we're really in the final stretch. Good timing, as we only have two weeks till the capstone presentation!

We added a little screen to display the current settings of the instrument (and potentially do other things).

There were two ways we could have set up this screen, and in the end I decided that the method that uses more wires to update the screen faster was the way to go (even if it caused me some pain when it came to actually wiring it).
In addition to using the faster wiring to avoid lag that would disrupt sound generation and input response, I programmed it so that the screen is only drawn to when settings are changed, meaning that no processing time is used up by drawing to the screen unless the user is changes a setting.
I've taken the Wamboard home this weekend to do some measurements for it (and add a completely superfluous feature).
Here's a side panel that I'm going to 3D print to affix to our wooden exterior to cover up the ports with the exact openings we need for ports and knobs.

I didn't include this in the laser-cut wood pieces because I wasn't sure what ports we would need and because I want to be able to swap this out in the future if we change the I/O somehow.
By the way, we'll try to print this in orange, not green. Maybe black if there's no orange.
This is the real reason I took it home over the weekend. (Well, not that the measurements weren't a real reason, but, you know, this was another motivation.)

Hopefully I can surprise Weston with this on Monday.
It's really satisfying to have it all put together and in a playable state. I've just been tinkering with it at home when bored/procratinating/waiting-to-go-somewhere,which is exactly what what I intended to make with this project; a fun little novel instrument.
