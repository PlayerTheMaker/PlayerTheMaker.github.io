4/20 - 4/24

Finally finished the box!
We finally added a proper volume knob!

We actually did this mainly because the amp was freaking out when the recieved signal was too high.
We kinda needed one anyway, though. The code for this is pretty simple, the arduino reads the potentiometer signal and modulates the output volume accordingly. For some reason putting the potentiometer between the arduino output and the output headphone receptacle didn't work (which I suspect has to do with the nature of PWM signals).

So I got to getting the guts of our machine into the new case. The wiring had to be tweaked a bit (which also required some minor code adjustments that I haven't got quite right yet) but it seems to be working...?
I haven't got all the keys mounted yet, though, so it'll remain mostly unplayable this weekend.
Three weeks till the showcase!
